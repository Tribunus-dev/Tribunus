# ADR to ACR Cross Reference Matrix

ADR 0021 imports ACR 0001 through 0005 and extends the Tokio Phase Scope and IOSurface Runtime Island components.

ADR 0022 imports ACR 0001 through 0005 and extends Durable Authority Receipt and Receipt-Before-Ack Ordering.

The current matrix is intentionally small. It proves that the component board can be imported by ADRs, extended by ADRs, and inspected for contradiction boundaries before the validator grows more sophisticated.
